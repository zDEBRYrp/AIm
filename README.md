# AIm — AI Aimbot

**AI** + **m** = **AIM**

Нейросетевой аимбот для CS2 на основе YOLOv8n. Захват экрана через mss, инференс через onnxruntime — работает на CPU, GPU не нужен.

## Запуск

```bash
pip install -r assets/requirements.txt
python start.py
```

При первом запуске автоматически скачивает YOLOv8n (~6MB) и экспортирует в ONNX.

## Управление

| Клавиша | Действие |
|---------|----------|
| F1 | Переключение режима: Всегда вкл / Hold |
| Mouse4 | Аим (только в режиме Hold, зажимай) |
| 8 | Открыть настройки (когда консоль в фокусе) |
| 0 | Выход |

## Настройки (клавиша 8)

Меню с вопросами через questionary. Навигация стрелками, Enter для выбора, Esc для сброса к дефолтам.

| Пункт | Описание |
|-------|----------|
| 1 | Уверенность (0.05-0.95) — ниже видит больше, но врёт чаще |
| 2 | NMS IoU (0.1-0.9) — давит дубли боксов |
| 3 | FOV (px или `full`) — размер зоны захвата |
| 4 | Скорость аима (0.05-2.0) |
| 5 | Макс шаг (1-200 px/кадр) — защита от рывков |
| 6 | Мёртвая зона (0-50 px) — внутри зоны мышь не двигается |
| 7 | Высота прицела (0-1) — 0 верх бокса, 0.2 примерно голова |
| H | Кнопка hold (x2 / left / right) |
| T | Хоткей переключения (напр. F1) |
| M | Монитор (primary или номер) |

Все настройки применяются сразу и сохраняются в `config.json`.

## Мониторинг

Отдельный скрипт для просмотра детекции без аима:

```bash
python monitor.py
```

Показывает все классы COCO с цветными боксами и подписями. Выбери монитор при запуске. Выход — `q` в окне.

## Прицел для CS2

Импортируй код в CS2 (Настройки → Игра → Прицел → Импорт):

```
CSGO-FZUXv-VVbLD-EDy3c-kYqf3-UMkTL
```

Точечный прицел — нейросети так точнее, линии не мешают детекции.

## Важно

- **Выключи** «Повышение точности указателя» в свойствах мыши Windows
- Используй точечный прицел в CS2
- При двух мониторах: аимбот работает на основном, монитор можно сменить в настройках (пункт M)

## Требования

- Python 3.10+
- Windows
- GPU не нужен

## Зависимости

- `pywin32` — Win32 API (SendInput, DPI)
- `mss` — быстрый захват экрана
- `opencv-python` — обработка изображений
- `onnxruntime` — инференс YOLO
- `numpy` — массивы
- `keyboard` — глобальные хоткеи
- `pynput` — управление мышью
- `questionary` — меню настроек

```
├── utils/

├── models/
│   └── yolov8n.onnx  # Модель (auto-download)
└── assets/
    └── requirements.txt
```
