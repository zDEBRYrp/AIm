## Про название

**AIm** — составное: **AI** (нейросеть) + **m** (получается AIM).
> Если уточняют: «AI Aim — AIm»


## Архитектура
- **YOLOv8n** → экспорт в ONNX → инференс через **onnxruntime** (150+ FPS на CPU)
- Захват экрана через **mss**
- PyTorch нужен только один раз — для экспорта модели
- Относительное наведение + залипание на цели + deadzone


## Возможности
- (F1) Смена режима: Всегда вкл / Hold
- (Mouse4) Аим пока зажата — работает ТОЛЬКО в Hold режиме
- (8) Меню настроек в консоли — FOV (или `full`), скорость, кнопки, монитор, видео-режим; Esc сбрасывает
- (0) Выход
- Окно детектора — видно, как модель распознаёт цели
- Все настройки в `config.json`


## Требования
- Python 3.10+
- Windows
- RTX не нужна — работает на CPU


## Как запустить
1. Скачай [Python](https://www.python.org/) (3.10+)
2. Склонируй или скачай репозиторий
3. **Выключи** повышение точности указателя: `Свойства мыши` → `Параметры указателя` → снять галочку
4. **Выключи RAW INPUT** в игре (если есть)
5. Запусти:
```
python start.py
```
Зависимости ставятся сами. Модель YOLOv8n скачивается и экспортируется в ONNX при первом запуске.


## Настройки

### Прицел для CS2
Используй **прицел-точку** — нейросети так точнее, линии не мешают детекции.

Импортируй код в CS2 (Настройки → Игра → Прицел → Импорт):
```
CSGO-FZUXv-VVbLD-EDy3c-kYqf3-UMkTL
```
Или вручную: включи **«Точка в центре»**, длина 0, толщина 0, зазор 0, обводка выкл.

### Меню настроек (клавиша 8 в консоли)
- FOV: размер зоны в пикселях или `full` на весь экран
- Скорость аима, макс шаг, мёртвая зона, высота прицела
- Кнопка hold, хоткей переключения, монитор
- Видео-режим «только детектор» (без наведения)
- Esc — сбросить всё к дефолтам


## Известные проблемы

**Целится в землю** — выключи raw input + повышение точности указателя.

**Valorant** — нужен kernel-драйвер для обхода ограничений ввода мыши.


## Как это работает

### YOLOv8n (ONNX)
Обучена на COCO (80 классов). Экспортирована в ONNX для лёгкого инференса на CPU через onnxruntime. PyTorch в рантайме не нужен.

### Захват экрана
`mss` — быстрый захват области экрана с минимальной нагрузкой на CPU. При нескольких мониторах используется основной (меняется в настройках).

### Управление мышью
Win32 `SendInput` — относительные перемещения, пропорционально смещению цели от прицела.
